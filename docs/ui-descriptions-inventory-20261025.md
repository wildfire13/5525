# スキル説明と大量所持品の実験

基点は `1acc000a4ef21a0073bbb47386596b96100c05a4`、ブランチは `experiment/movie-ui-brushup-20261024`。編成・商品比較と施設NPCの実験を保持した追加改善。ゲーム制度、性能・数値、native、保存形式・保存先は変更しない。

## 変更

- 戦闘スキルと人物の「スキル・効果」に任意の「説明」を追加。通常のスキル選択は従来どおり1クリック。名前/Lv、種別/消費MP、指定対象/効果範囲を固定し、効果・条件・期間の本文と共通用語を別タブで読める。
- `skill_text.gd` は既存定義と既存説明を読み取り、未登録の数値を補完しない。足払いの指定者自身と周囲8マスの敵を区別し、整数化で射程1と表示していた誤りを修正。魔力譲渡のMP0と移譲分、帰還のアクティブ扱い、条件成立時/通常時の効果も保持。
- 説明窓は読取専用で、元のスキル選択・予告を保持。人物、所持品トークン、行動、接続などの文脈が変われば閉じる。更新待ちは開かない。小さくしても戻る操作を画面内に保持する。
- 装備の基礎能力と付与スキルを区分。既存の装備メモは原文のまま別枠・別タブへ。所持品を選んだ後の「説明」で未装備品も全文を読める。ホバーは高さを制限した要約で、全文への案内を表示する。ショップ比較は既存の正規予告APIを維持する。
- 所持品一覧のみをスクロールし、選択品名、個数、正規売却額、残金、確認/戻るを一覧の外に配置。選択行は枠と文字で示す。NO/Esc後も同じ人物・品目・個数・分類・編集位置を保ち、一覧へ戻ると開始位置とフォーカスを復元する。旧人物の遅延した金額応答は破棄する。
- アイテムの戦闘説明を既存の個人所持品・Lv別範囲に整合。空いた各手の拳、戦闘外のアイテム使用、ポーター受注条件は保持する。

## 検証方法

Godot 4.6.3 / Linux、専用の外部XDGプロファイルと検証用セーブを使用。BGM・ボイス・SEはOFF、音声出力はDummy。表示の確認はheadlessテストと区別し、X11実描画とXTestのOSマウス/キー/ホイール入力で1920×1080と1180×812を操作する。

```sh
python3 godot/tests/run_inventory_header_261020.py --evidence /absolute/external/qa
python3 native/check.py
DISPLAY=:isolated BRUSHUP_GUI_WIDTH=1180 python3 godot/tests/run_facility_gui_261022.py --script research2_gui --evidence /absolute/external/gui-1180
```

`research2_descriptions.gd` は既存定義の種別/費用、未設定値、Lv、条件、指定と範囲、長文末尾、戻る、文脈失効、未装備品の全文/原文を確認する。`inventory_context_regression.gd` は49種類の実在品目、分類、選択行、数量変更、NO/Esc、再読込、遅延応答と人物切替を確認する。旧shop行テストの取消後の再選択操作だけを、同じ品目・個数・人物へ戻る強い状態検証へ置換し、実売却額と所有者の検証は保持した。

最終の標準runnerは27/27合格（説明85項目、所持品44項目を含む）。nativeは23/23段階、固有回帰7本も合格。Pythonは162件中161合格・Windows固有1件スキップ。実描画/OS入力は両解像度で各74/74合格。独立レビューでは種別/費用/最小窓34、更新待ち競合9、所持品44、未装備品の長文/原文21、長いタイトルと対象説明の最小窓6項目を追試し、すべて合格。既存のImage直接読込警告は素材テストに残るが、最終runnerにERROR・FAIL・leakはない。

## 評価の境界

新しい倉庫・スタック・容量、スキルや条件分岐の新設、フレーバー本文の創作改稿、成長/勝利表示の次段階は含めない。従来の編成・購入・スキル選択に必須の操作は増やさず、任意の全文確認のみ1クリックを追加する。売却取消後は再び品目を選ぶ操作が不要になる。

Windows実画面、ユーザー本人の追加分プレイ確認、実聴、専用の性能測定は未実施。ローカル検証、GitHubへのpush/CI、mainへのmerge、ユーザーPC反映は別々に扱う。この追加分は結果報告後のpush判断を待つ。
