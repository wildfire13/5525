# 売買UI改善（2026-10-30）

## 変更
- 比較窓を横に広げ、本文の重複見出し・対象行・装備基礎能力・長い補足を整理。購入は従来どおりインベントリへ入り、自動装備しない。
- 追加／失うスキルは個別アイコン＋Lvで表示。ホバーで付与部位／付与枠と効果全文、クリックで詳細窓。重複付与の個数差・異Lvを維持。旧素材に該当Lvバッジがない場合は比較欄だけ原画と正しい併記Lvを使用し、Lv1バッジの誤表示を防止。
- 購入ボタンはスクロール領域外へ。金貨アイコン・価格・可否の緑／赤。選択した受取人の空き枠を純粋な見積りで確認し、確定処理の再検証も維持。
- 装備条件の職業名が一律ポーターになっていた誤表示を修正。装備条件と購入条件は別。
- 売却パネルを保持し中立色へ。青は下部の選択人物だけ。右上×と最下部「売却を終了する」を追加。従来のステータス内売却も保持。
- 所持金は確定応答の残高を基に短いカウント表示と増減ポップアップ。操作待ち時間は追加しない。読込／新規開始は演出を解除して実残高へ合わせる。

## 検証
変更範囲に合わせた対象検証を実施。価格・取引可否・枠上限・保存形式・ゲーム効果のルール変更なし。CI設定は変更しない。

- 新規native試験：職業条件、装備不可品の購入、受取人の枠不足／既存スタック、見積り無変更、正確な支払い、二重購入拒否、保存再読込が成功。
- 既存native：売買9群、装備制約6群、容量6群が成功。
- Godot専用回帰28/28：取消／確定、数量、二重売却拒否、両売却経路、背景戻ると両出口、金額、可否色、スキル重複・Lv、1920×1080／1180×812／960×540の購入ボタン可視性。
- 既存施設回帰76/76成功。初回は試験起動の音声OFF指定漏れによる末尾確認失敗があり、指定修正後成功。
- Linux実描画＋XTestのOSクリックでも同28項目成功。試験用人物・在庫を読み込んだ後の操作であり、新規開始からの自然プレイではない。
- 最後のLvバッジ修正後、実描画の比較・全文ホバー（FHD／960）と金額の増減・消失／リセットを再確認（9確認成功）。FHD／1180／960の比較窓、FHDの売却パネルを画像実見。本文は960ではスクロール、購入ボタンは固定。

## 調査判断と限界
- 「戻る」の不具合は、今回の施設売却と状態詳細から戻った後の対象経路では再現せず。既存導線は維持。
- 旧素材のバッジ不一致は実画面で発見し比較欄だけ補修。他画面の素材体系を変更しない。
- 試験データの必要STR不足・保存済み窓寸法を新品初期値と誤認する試験不備を修正。製品の装備制約やユーザー保存サイズを緩和していない。
- Windows実UI、ユーザーPC、高DPIは未確認。Linuxはllvmpipeで確認。全体フル回帰をローカルで追加反復していない。
- 原本Excelは全3シート・7画像・図形注記を確認。最新ユーザー訂正の「売却パネル維持／青は人物だけ／両経路売却」を優先。私用資料はリポジトリに同梱しない。
