# 売買比較の回帰テスト更新（2026-10-30）

## 原因と対象

main `54716daff2a1b8091410662e33749df2937bea0a` のLinux CI run 41006322084で、`brushup_comparison_regression`の5件が失敗した。
売買改修 `769f6e3` はユーザー指定により、人物選択欄と重複する本文の「対象：人物名」を削除していた。一方、テストは本文に人物名が残ることを要求していた。今回のUI方針改善マージで比較実装・当該テストは変更していない。

製品表示やCI設定は変更せず、既存仕様に従ってテストの照合先を更新する。

## 失敗5件の変更前後

| 旧assertion / 実行条件 | 変更前 | 変更後 |
|---|---|---|
| `comparison names owner and item 1920` | 比較本文に「ガロ」「木製の片手槍」が含まれる | 人物選択欄のIDと表示名がguard/ガロ、商品見出しが木製の片手槍、本文全体がguardの独立取得した正規previewGearに基づく比較と一致 |

| `owner switch replaces old comparison` / 1920×1080 | 本文にミオが含まれガロが含まれない | 選択欄がmage/ミオ、本文がmageの正規比較全体と一致し、guardの比較とは異なる |
| `owner switch replaces old comparison` / 1180×812 | 同上 | 同上、1180×812 |
| `late old owner response cannot overwrite current comparison` | 新本文にミオを含み、遅延した旧応答の解放前後で本文が同じ | 解放前にmageの正規比較と一致・guardと不一致を確認。解放後は旧応答の保留が実際に終了したこと、選択欄がmageのまま、本文がmageの正規比較と一致・guardと不一致を確認 |

正規比較は選択中のUIキャッシュからではなく、指定した人物IDでエンジンへ別途要求して取得する。文字列整形は既存formatterを使用するため、formatter自体の誤りを独立検出する検査ではない。既存の固定期待値（ATK 26→23、符号付き増減、正規ATK=23）も維持し、数値検査を削除しない。金額・取消・二重購入防止・保存状態不変・通信失敗等の既存検査も保持する。
