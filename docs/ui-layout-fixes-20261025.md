基点は `a4b0d8d72238fea0a21508296eaed4fd38d3094b`。`experiment/movie-ui-brushup-20261024` 上の追加修正。ゲームルール・データ・セーブ形式と互換性、編成・正規比較・施設NPCを保持する。

## 修正

- **装備中アイテムのホバー**：案内文だけ初回測定時の幅が未設定で、細い幅への折返しが背景を過大にしていた。さらに本文の固定280px高が通常のスタンプ等の説明を途中で切っていた。全要素を最終幅・フォントで測り、通常本文は実際のRichText高を確保する。画面高を超える長文だけ、完結した原文ブロックの抜粋と続きの案内を表示する。元の説明・原文メモ・全文確認経路は保持する。
- **開いた説明窓を保った親の縮小**：最小サイズを親の利用可能範囲へ合わせ、親の拡大時には元の最小サイズを復元。本文領域の固定最低高を外してフッターを確保する。保存済み窓の再オープンで上余白を重複加算しない。リサイズで元のControlが再生成されても、同じ人物・スキル・接続文脈のボタンへフォーカスを戻す。
- **戦闘履歴・順番詳細**：浮動パネルの復元・ドラッグ・サイズ変更で下部操作帯を避ける。5枚の行動順情報は維持し、狭い画面では横スクロール。順番詳細ボタンはスクロール範囲の外で画面内に収める。実行・キャンセルの判定と動作は変更しない。
- **低い人物窓の所持品操作**：一覧高の下限を120pxから44pxへ下げて操作領域を優先。説明・装備・一覧戻り、売却確認・一覧戻りをそれぞれ同列へまとめる。人物・品目・数量・正規金額・分類・起点スクロールとフォーカスを保持する。
