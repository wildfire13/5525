# 下部メッセージとパーティ位置の安定化

共通メッセージ欄は空欄時に非表示になり、縦コンテナから1行分の高さと間隔が除かれていた。パーティ列はその上の伸縮領域の末尾にあるため、表示の有無で上下に移動した。

## 修正

表示中の位置を基準に、対象画面ではメッセージが空でも欄を残す。現行フォントの1行高を最低高さとして確保し、本文は空のままにする。空欄はクリック・キーボードフォーカス対象から外す。文字がある時は従来の全文説明を開ける。商店・ギルド・戦闘の既存非表示方針は変更しない。

本文、フォント、メッセージ優先度、フォーカス移動時のメッセージ更新方針、ゲームルール、セーブは変更しない。吹き出し修正を保持する。

## 検証

`godot/tests/status_footer_stability.gd` はFHD、1180×812、960×540で表示あり/空欄/処理中/長文/エラー/フォーカス移動のパーティ列・メッセージ・地名帯の座標を比較する。長文の全文表示と閉じる操作、他施設の表示方針、保存データ不変、音声3種OFFも確認。GUI時は実OSクリックとTab/Escape、headless時は直接フォーカス操作として区別する。

修正前の実測パーティ上端は、FHDが876→917、1180が620→661、960が362→403。いずれも空欄で41px下がった（文字行33px＋間隔8px）。修正後は表示中の座標を維持する。

Windows実UI/DPI・実GPUは未確認。今回の反映範囲はローカルcommitのみで、push・CI・本人PC操作は行わない。
