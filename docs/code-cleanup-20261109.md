対象は `b11278f`。Git管理下の GDScript・シェーダー・JavaScript・Python・PowerShell 計428ファイル（テストを含む）を棚卸しした。製品側はファイル規模と複数ファイルで一致する連続行を手掛かりに、通常の起動経路、主要関数の呼び出し元、既存の回帰検査を読んだ。全行の個別レビューや素材評価はこの調査の対象外。

## 現状の分担を維持した箇所

- `godot/main.gd` の `update` は長いが、要求の直列化、再接続時の世代判定、ロード画面と結果通知の終了順に依存がある。ここを扱う際は、通信中の切断・終了・連続コマンドを先に再現してから境界を決める。
- 後続の方針決定で、ゲームの入口をGodot版に統一した。Python/Tk画面とその専用テストを廃止し、Godotが使うファイル・画像・SQLite処理とバックエンドの検証は継続する。
- 戦闘HUDのボタン選択は通常画面の `mark_selected` に統一した。スキル・アイテム・陣形の選択状態には通常画面のメタデータと配色を使う。
- nativeの装備・戦闘表示とGodotの店舗比較などはすでに用途別のモジュールを持つ。今回の棚卸しでは、ファイル長だけを理由にそれらを再分割する利点は確認できなかった。
