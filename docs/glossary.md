## 2. 混同・自動置換を避ける語

- **旅人**：ゲーム内キャラクターの総称として特に定義しない。一般名詞として使うことや、ゲーム内に旅人が登場することは問題ない。既存の「キャラクター」「仲間」「冒険者」を「旅人」へ一律に置換しない。Site名「5525｜旅人図鑑」は固有タイトルとして区別する。2026-11-05 JSTの本人確認による。
- **29名の名前登録／24人の登録候補／パーティ最大12人／戦闘出場5人**：別の数。29名の全員がゲーム採用済みという意味ではない。
- **キャラクター素体属性／攻撃成分属性**：別の対象。実装の職業別属性は暫定配分で、名簿の空欄を確定設定として埋めない。
- **RP／EXP**：成長対象が異なる。基本報酬／希望条件達成報酬は報酬の区分、RP／EXPは報酬種別であり分類軸も異なる。
- **AGI／SPD、所持枠／Wt**：基礎値と最終値、種類数と重量をそれぞれ分ける。
- **防御／かばう／防衛線**：基本行動と二つの技能を区別。「防衛線」は「かばう」の旧名ではない。
- **現行名／旧テンプレート名／物語案の仮名**：名前の対応はS2を基準とするが、ガロ・リノ・ミオ・ニカ・トワは旧実装テンプレートにも登場する。「全て未採用の創作」とはしない。旧名から新名への一対一対応を推測しない。
- **UIラベル／説明語／コード識別子**：コード上のguardは文脈により職業・技能・防御行動に関係する。表示名からjob_warrior等を作らない。保存互換キーも表示統一と一緒に変更しない。
- **現行仕様／モック先行／試験実装／最終バランス**：採用状態が異なる。モックに表示があってもゲーム本体の実装証明にはならない。

## 4. 未決・提案として残す事項

1. **統一スタイル**：「火」と「火属性」など、短いラベルと説明文の使い分けは、この文書では現行併用を保持する。全画面での一律改名は提案段階。
2. **5525の読み**：公式な読みを確認するまでルビは付けない。
3. **ポーターのC01**：ホイッスルの実装があっても攻撃・手装備方針全体の保留を解除しない。
4. **数値**：Wt・攻防値、単発依頼の時刻・報酬等に残る試作値を最終設定として固定しない。両手・片手の火力比較は数値検証の問題で、装備枠名称の変更とは分ける。
5. **詠唱・中断**：初稿の「被ダメージやノックバックで詠唱中断」という一般化は削除。確認できるスタンプの構え・足払いによる中断を個別に記載した。その他の詠唱ルールは別途出典確認が必要。
6. **用語数**：集計対象が未定のため総用語数を宣伝しない。マスターのequipmentGrants 59件は付与関係の件数であり、用語数や技能数ではない。S1の技能・効果32種、装備68件（空枠8件を除く）とも異なる。
