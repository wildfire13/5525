# A/B比較後の必須修正 — 2026-11-06

対象は `ui/mock-ui-migration`。比較時の版 `73a785f` に対し、情報欠落・誤操作・操作不能を先に修正した。元のA/Bレポートは比較時点の記録として保持する。

## 修正内容

- **装備比較**：部位選択と比較対象、単一の装備ボタンを連動。比較取得中は実行不可とし、連続選択による古い応答を破棄する。左手の盾を投げ槍へ変更したとき、表示DEF9→7と実際の結果が一致する。
- **インベントリ**：破棄を個数指定・確認付きで復旧。キャンセルと画面状態変更時の誤実行を防ぐ。分類フィルタを復旧し、装備品には消耗品の使用対象ボタンを表示しない。
- **能力・スキル**：EXP、種族・職業、通常ATK・射程・属性ATKを復旧。補正値を各数値に隣接。スキルは定義に従いアクティブ／パッシブへ分類し、付与元・レベルを保持する。
- **道中**：経路選択に所要時間と敵人数を併記。往路の区間と帰路に対応する既存の遭遇人数を表示する。期限警告は復活させない。
- **ショップ**：商品詳細へ装備の補足説明を復旧。「戦闘後に回収する」など購入判断に必要な効果が読める。
- **結果画面**：Tab順へ成長詳細を追加。Enterで展開／折り畳み、PageDownで内容確認、Shift+Tabで逆移動できる。
- **宿屋**：休息後の店員の応答を表示。全回復状態で再訪した場合も専用の台詞を表示する。
