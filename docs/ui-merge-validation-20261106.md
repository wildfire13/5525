# モック UI ブランチの main 統合検証（2026-11-06）

## 対象と範囲

- ユーザー指定元: `ui/mock-ui-migration`、開始時 HEAD `dde691441980f9570827b2df3badf97ee553725b`。
- 比較基点: `main` の `7280d622da7702097135216df255b3548b0029dc`。
- 承認済み B の UI、クエスト報酬、移動中の帰路を保持する。過去の「main へはマージしない」という記録は、その時点の作業条件である。
- 元ブランチを上書きせず、その後継の検証ブランチで修正と回帰確認を行う。未検証の失敗を成功扱いにせず、競合や並行変更は再確認する。

## 検出して直した問題

1. シナリオクエストの報酬詳細が `bonus` と `bonusRP` を隠していた。窯・蕪・車輪の実 API 表示で再現し、通常クエストと同じ希望条件達成報酬の行を表示するようにした。支給額・期限・旧セーブ処理は変更しない。
2. 共通名簿の再描画でスクロール位置が失われていた。既存 `ui_memory` のスクロール記憶へ登録した。
3. ギルドの控えカードは中身の最小高さ 97px に対して 92px しかなかった。カードの最小高さだけを 100px にした。
4. 保持しているステータス部品で人物を切り替えた際、売却対象とショップ対象が一致しなかった。既存のガードを維持して対象 ID を同期した。旧部品への新しい導線は追加していない。
5. 共通名簿で人物を選択して再描画するとキーボードフォーカスが失われた。既存のフォーカス記憶へ人物ごとのキーを登録した。

本体変更は表示・ビュー状態の同期に限定する。ゲームルール、採用素材、セーブ形式、支払い・報酬処理は変更していない。

## 回帰テストの移行方針

基点の既存集約は 66/66 工程成功。固定した元ブランチでは、旧ノード・旧配置・旧操作フローへの期待が失敗した。これを既存 CI の故障や無関係な失敗として無視せず、新 UI の同じ操作目的へ移植した。

- 下部人物バーから共通名簿、旧商品別操作から中央の比較・取引、旧ギルドの直接交換から明示交換へ移す。
- 金額・個数・所有者・荷物の永続化、取消後のセーブ完全一致、二重送信、古い応答、保存上限、切断時の再送防止を保持する。
- 新 UI から直接使わない横バー・ステータス・比較ダイアログ・吹き出し部品は、必要な部品試験と実画面の導線試験を区別する。
- マップ、戦闘、宿屋の配色・配置・文言は、承認済み B に合わせる。旧デザインを復活させるために本体を変えない。
- 既存集約の工程は削除していない。新規 `quest_reward_display_regression.gd` は実 API の通常・シナリオ・受注前後・旧セーブを使い、155 項目で金額/EXP/RP/表示時の保存不変を検証する。
- NPC の 600 回の乱数検査では検査済み画像を強参照で保持する。弱キャッシュによる再デコードを避けるだけで、試行数や選択条件は減らさない。

## 実行方法と CI

```sh
python native/check.py
python godot/tests/run_inventory_header_261020.py --evidence /tmp/5525-legacy-check
python godot/tests/run_mock_ui_regression.py --evidence /tmp/5525-mock-check
```

Godot のインポート後に実行する。Node 24 / Python 3.12 / Godot 4.6.3、隔離プロファイル、1920×1080、headless/Dummy を使う。新 runner は外部の証跡ディレクトリを要求し、各試験を隔離、タイムアウト時に子プロセス群を停止する。

元ブランチの native 集約は 32/32 工程成功。Python は 213 件中 212 件成功・Windows 専用 1 件 skip だった。過去に記録された旅 fixture の失敗はこの環境では再現しなかった。今回の修正で native 実装は変えていない。

最終 commit の成否は PR に紐づく CI を確認する。個別試験の成功や途中の探索実行を、最終全件成功とは区別する。

- 既存 Linux と Windows の CI に main 向け PR トリガーを追加する。
- 既存 CI の 15 分上限、並列設定、権限は維持する。
- 補助 `Mock UI and journey regression` は native の報酬・帰路ルールと FHD の新 UI 集約 17 本を検証する。
- 検証 commit `fb05827` の Windows と新 UI 17 本は CI 成功。既存 Linux は 54/66 工程が全て成功した時点でジョブの 15 分上限に達した。失敗項目は検出されなかったが、残り 12 工程と後続 native 検証はその run では未完了であり、成功扱いにしない。

## 検証の限界

今回のクラウド実行には実 GPU の画面目視、OS 入力での全編プレイ、実音声の聴取、ユーザー PC の起動確認を含めない。ヘッドレスの座標・入力状態・保存比較と、それらを混同しない。ローカル実行の Pillow は 13.0.0、CI 固定値は既存の 12.3.0。並列負荷による探索のタイムアウトは、テスト失敗や最終 CI 成否と分けて記録する。
