# 施設・全文ホバー・背景・音量UIの調整

基点: `79086fb71ed883eff42f6eed89a965f564458d69`。専用branch: `experiment/feedback-ui-20261026`。ローカル適用・検証済み、push/main統合前。

## 変更と判断根拠

- 施設NPCは元PNGを加工せず表示を拡大。顔・上半身を右側に大きく配置し、下半身は画面外cropを許す。操作UIは前面、装飾はmouse ignore。狭画面では操作を優先する既存の非表示条件を維持。武器屋男女の滞在内固定・等確率の表示専用乱数を保持。
- 町・施設・地図など既存スチル画面を全画面の比率維持coverにし、UIを重ねる。地名・場所・所持金を非戦闘の下部共通帯へ集約。顔のホバーを残し、顔カード下の重複説明を除去。戦闘・配置は従来から金額表示がなく、今回の背景スチル改修と別のHUD/カメラなので既存配置を維持。
- 人物装備hoverは画面全体で測定した全文を同じホバーに表示する。別画面への誘導と抜粋方式を廃止。能力・条件・スキル効果・原文メモは保持し、極端な長文だけ同じ表示内でスクロール。比較/他の装備hoverと排他にし、対象の切替・削除・ドラッグ・閉鎖に追従する。埋込Windowの入力透過に依存せず、前面CanvasLayerの非入力Controlで表示し、通常の人物/商品クリック・ドラッグを通す。長文はホイール専用と明示して非操作のスクロールバーは表示しない。人物窓外の同じ矩形では盤面入力を遮り、メニュー/別Windowが開いた時は退避する。
- メニューは再クリックで閉鎖する。Popupの外クリックhideから同clickによるreopenが起きたため、同画面内パネルと遮蔽でトグル/背景入力防止/Tab循環を両立する。
- 音量はOn/Off併存を避け、BGM/ボイス/SEごと0〜100%の10%刻みスライダーへ一本化。0%は無音。100%は既存のBGM -6dB/voice 0dB/SE -4dB/UI -6dBのミックスを保つ。古いミュート設定は読み込み時に書き換えず実効0%として表示し、利用者の正値操作で音量とミュート解除をまとめて保存する。設定はゲームセーブと別のローカルConfig。
- 製品初期ONと、QA開始時のBGM/ボイス/SE OFFを明示分離。`NATIVE5525_AUDIO_OFF=1` は保存設定を上書きしない試験用override。音量/イベント検証でのDummy出力は実聴と区別する。
- AGENTS追記は文書に合わせるだけの挙動変更を避け、最新指示・仕様・コード・テストを照合して判断する方針。成功中の既存コード/テストも既知バグの正当化には使わず、根拠不足の論点のみ推奨案付きで確認する。
