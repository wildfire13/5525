# 単発クエストQA後の確定バグ修正

基点: main `22e0b190ec0bb88d9438ef19487e587cd7e82b95`。単発3件のQAから、仕様追加を要しない表示不具合2件を先行修正する。時刻・報酬・荷物・物語・納品条件は変更しない。

## 修正と根拠

1. **依頼者を「受取人」と表示**
   - `quest_board.gd` は `client` を「受取人」と表示していた。単発の `client` は農夫・若い陶工・車輪職人であり、現行の納品会話と一致しない。
   - 単発だけラベルを「依頼者」に訂正する。新しい受取人データや正式名称は追加しない。通常クエストの表示は変更しない。
2. **期限超過による失敗を「護送隊が敗北しました」と表示**
   - カブ19時間・窯21時間・車輪37時間で、正しい納品先から `completeQuest` を実行すると期限失敗するが、`result.reason` がなく戦闘敗北の既定文へ落ちていた。
   - 失敗結果へ「納品期限を過ぎました。世界の時刻は巻き戻りません。」を追加する。
   - 旧セーブの同じ期限失敗にも、`view` でのみ理由を補完する。保存データは書き換えず、既存の理由と単発以外の失敗表示を保持する。
