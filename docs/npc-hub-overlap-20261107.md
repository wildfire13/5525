`c2f40aed` を基点とするローカル候補 `fix/npc-hub-overlap-20261107`。公開、mainへの統合、通常PC環境への反映は行わない。NPC待合せの導線は維持し、案内と施設操作を重ねない。

旧main `22e0b190` の拠点案内は下部 `y=.82`。`c2f40aed` で右側 `x=.70〜.99 / y=.04〜.96` の案内パネルを追加した一方、宿屋の `x=.64` と幅168pxを据え置いたため、案内が施設を覆う新規回帰になった。Windows担当の描画・Control矩形とLinuxのControl矩形が一致した。単なる文字の見切れではなく、パネルの入力遮断により覆われた位置のクリックも届かない。

- 1280×720参考条件: 案内左端974px、掲示板866〜1034px。重複60×64px。

## 修正と互換性

- 行商人の案内が出ている間だけ、施設の右端を案内の左16pxまでに制限する。元のアンカーに収まる施設は動かさない。縦位置、ボタンサイズ、背景と人物素材、案内の内容は維持する。
- ライブリサイズ時も元のアンカーから再計算し、縮小・拡大を繰り返して位置補正が蓄積しないようにする。案内のない拠点は従来配置のまま。
- 期限切れ精算ボタンの長文は自然に折り返す。1280×720で最小幅が案内パネルを画面外へ押し出す問題を防ぐ。文言と処理は変えない。
- エンジン、保存形式、契約、時刻、報酬、納品条件、施設操作は変更しない。実セーブは使用しない。

修正後FHDの宿屋は1229.60〜1397.60px、案内左端1413.60pxで16pxの間隔。1280×720の掲示板・宿屋は右端958px、案内左端974pxとなる。
