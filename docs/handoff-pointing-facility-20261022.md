## この候補で変わること

- ホバーを既存クリックと同じ `cell_at → unit_at` に統一。人物画像の不透明部分が隣マスへ重なっても優先しません。
- 空マス・盤外へのホバーイベントでは右欄の人物情報と予測を消去し、保留中の行動自体は保持します。明示的な対象選択時の能力表示は従来どおりです。
- クリック時の keyboard_cell 更新を grab_focus より前へ移し、初回クリックで古いフォーカスマスを表示する問題を修正。
- 施設背景は専用 RNG を使い、所在地と施設ページの組で訪問を保持。同じ訪問の再描画・購入・フィルター・モーダル操作では固定し、ページ離脱後の再入場で再抽選します。連続同一画風は許容。
- ロード・新規開始・切断時のコンテキスト初期化でも訪問を初期化。戦闘／木人への移行は施設離脱扱いです。セーブ形式・進行 RNG は変更しません。
- TextureRect → 暗色レイヤー → 既存 UI の順で表示。背景は縦横比維持、マウス入力無視。素材がない場合は従来の親コンテナをそのまま使用。
