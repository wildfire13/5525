# Wt・属性ダメージのテスト実装（2026-11-02）

本項目はユーザー指示による試験実装。重量・装備防御・属性攻撃の数値は仮配分で、最終バランス調整済みではない。

## ルール

- Wt上限はキャラクターの最終STR。装備・成長等のSTR補正を含む。装備と所持品の数量分を合算し、Wtが上限と等しい場合は通常、超過時は所持可能だが最終行動速度を50%にする。装備中の同じ両手武器参照は1回、左右の別実物はそれぞれ計上。空枠・素手は0。
- 選択中のパーティで戦闘不能のキャラが持つ全重量は、生存者（戦闘配置外を含む）に均等に加算する。所持権は移さず、小数のまま扱う。全滅時は除算しない。復帰時は共有を解除する。
- 戦闘不能はアスタリス宿屋のみ復帰。道中休憩・野営は戦闘不能者を0HPのままにし、KO対象への回復アイテムは使用不可。生存者回復と宿屋の従来費用/全選択者回復は維持。
- 物理/火/水/地（木を含む）の各攻撃成分から対応する防御値を引き、成分ごとに0未満を0へ丸める。火は地に、水は火に、地は水に有利で1.25倍。不利側は0.75倍。同属性・無属性キャラ・物理攻撃は1倍。相性後に既存の陣形/かばう/ガード補正を適用し、合計damageを整数化する。
- 敵はマスター装備と個別inventoryを持ち、既存の敵用回復薬 stockを1人1個まで割り当てる。旧battle saveも残数を個別inventoryへ移す。装備品を新たなdropとして販売/回収する仕組みは追加しない。

## 仮Wt配分

既存Wtは原則保持し、Wt未設定の武器・防具は種類/素材/部位を基準に割り当てた。例として木の短剣2、布鎧3、木盾4。ポーション/エーテルは1。素手・空装備・virtualDefaultは0。`native/data/master-source.json`が生成元、`native/data/master.sqlite`が実行DB。DEF値と魔法ATKの配分も同ファイルにある。

## 属性・互換性

新規キャラ属性はジョブ別の暫定属性、ポーターは無属性。旧セーブで属性フィールドが欠損しているキャラは、そのキャラのtemplate/jobに対応する新規キャラと同じ暫定属性へ移行する。明示的な`none`は保持する。battleのweightRevision / equipmentRevisionを用い、既存戦闘データへ不足項目を一度だけ付与する。再ロード時に戦闘中KOや敵inventoryを上書きしない。

## 検証

`native/test_weight_elements.cjs`がWt境界、KO共有、復帰制限、相性/DEF順、敵装備と旧save roundtripを検査する。`native/check.py`とLinux CIへ登録。
