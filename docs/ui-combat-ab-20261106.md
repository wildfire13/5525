# 戦闘UIのB統一とA/B再比較 — 2026-11-06

## 改修

戦闘開始時に旧ダークテーマへ戻っていた処理を変更し、Bの紙色・濃色文字・緑の選択と実行ボタンを採用。本文20px、見出し28px、HP予測30px。減少は濃い赤、回復は濃い緑。詳細ウィンドウも共通テーマを使用する。

左に行動者・コマンド、中央に盤面、右に対象・効果・確定操作、下に行動順・履歴。左右の上辺・下辺を揃え、既定配置では50マスを情報パネルが覆わない。パネルのドラッグ・リサイズは維持。旧配置設定は新しいキーへ移行し、新規既定配置から調整できる。人物がAより小さくなるトレードオフはレポートに明記。

左の概要はHP・MP・SPD・Wtと属性アイコンに絞り、防御・属性攻防などは既存の能力・行動条件の詳細で確認可能。スキル・アイテムの展開、予測、取消、実行、履歴の処理は既存APIを維持。

共通メニューに「ゲームを終了する」を追加。ウィンドウを閉じる場合と同じ `close_game()` に接続。自動保存は追加していない。FHDで終了・閉じるまで収まるようメニュー高さを760pxへ調整。

- combat_b_ui：10項目。実GPU描画、投影座標へのクリック入力、移動仮置き/取消、防御の実行と手番進行、50マスの表示、パネル非重複、Bテーマ、左右上辺、終了項目。

- inventory_battle_hud：12項目。所有者別在庫、攻撃/回復予測と実データ一致、非消費、取消、MP回復対象。GPU版で赤/緑予測の表示も確認。
- mock_deployment_regression：14項目。配置、控え、陣形、リセット、戦闘への遷移。

人を集めた統計試験、全編プレイ、音声実聴、全解像度対応を意味しない。旧全体テストの既知問題を解決したという判定でもない。今回もローカルコミットのみ、push/mergeなし。
