基点: efb8b1aee8fdd6fd7b4e9edbd7053e7efe9f5a65。製品 main の push は GUI 確認後の指示待ち。

## 変更

- 配置中の味方情報・選択欄を左、クリックした敵の情報を右へ分離。ホバーでは右の選択を上書きしない。
- 味方クリックは選択、空きマスクリックは移動、ドラッグは移動・交換。選択対象の情報を左へ反映。
- 画面下部に陣形窓を追加。基本配置・切り込み配置は横幅を均等配分し、最小幅140pxを確保。
- 配置リセット・戦闘開始を右下に独立配置。手動配置の置換確認と取消・二重送信防止を維持。
- 配置用左右窓は deployment_ally / deployment_enemy として位置・サイズを保存。戦闘用の保存値は変更しない。
- 配置用窓の移動・サイズは左右の専用領域内に制限し、下部の陣形・開始操作と重ならないようにする。
- 戦闘開始時は配置専用操作を非表示にし、行動順と戦闘用窓を復元。街への帰還・再入場でも配置用保存キーを復元。
- エンジンの戦闘・陣形ルール、カメラ、CCT、保留装飾品は変更なし。

## dot クラウド PC の実操作手順

1. 別の検証用 checkout に bundle を展開する（同梱 RESTORE.md）。FHD 1920×1080 で起動。
2. 街から出発し、経路を選んで配置へ進む。左に選択中の味方、右に敵クリック案内、下部に陣形窓、右下に2操作が見えること。
3. 味方をクリックし左の情報が変わること。敵をクリックして右の情報だけが変わり、味方の位置が変わらないこと。
4. 空きマスへのクリックで選択味方を移動。別の味方へドラッグし交換。左の情報が操作対象と一致すること。
5. 陣形切替の確認を取消し配置不変を確認。再度実行して切り込み配置へ変更。配置リセットも取消と実行を確認。
6. 左右窓を動かしサイズを変える。各専用領域内に収まり下部操作を隠さないこと。長い名前や多人数時は選択欄・スクロールで操作できること。
7. 戦闘開始を連打しても一度だけ開始。陣形窓・配置ボタンが消え、行動順と以前保存した戦闘用窓が戻ること。
8. 次の配置画面／検証セーブ再ロード／街から再出発でも配置用窓が復元されること。右ドラッグ・中ドラッグ・ホイールのカメラ動作を確認。

自動検証は headless の状態・シグナル・矩形検証。文字の実描画、OSマウスでの掴みやすさ、実際のGUIは未確認。
