親が独立再監査通過を報告した `5fd471c4a4d9e1f1aad5f8b9643f06c4d4178510` を基準に、別コピー `G:/Apps/Codex/2026-10-07/task/5525-reserve-policy-work`、別ブランチ `codex/reserve-policy-20261012` で実装した候補です。合格済みコピーを固定したまま、ユーザーの「控えには全てできない」「パーティに編成してないキャラは同行してない」「アスタリス以外では表示させなくていい」を反映しました。

## 調査と修正

| 対象 | 調査結果と候補の動作 |
|---|---|
| 所持品の使用・受渡し・装備・解除・廃棄 | 所持者と対象を編成中に限定する正規処理は既に存在。既存ガードを維持し、控えの拒否・無変更を追加検証 |
| 単品購入・購入計画・売却 | 編成中の所持者・受取人に限定済み。控えへの購入や控えからの売却も直接呼出しで拒否 |
| 仲間画面 | 四村でも全員の表示・控え選択が残っていた。アスタリスの町画面だけ全員を表示。それ以外は同行者のみ。FHD・狭幅とも控え欄自体を出さない |
| 道中と古い詳細画面 | 出発後も内部 `location` が出発地のままなので、所在地だけでなく `phase == town` を要求。古い控え選択を同行者へ戻し、隠れた控えの詳細・装備を再度開く呼出しも拒否。表示中の控え詳細は出発時に閉じる |
| 能力配分 | 控えへ配分できるUI/APIがあった。「全てできない」に合わせて編成中だけへ制限。能力確認とアスタリスでの再編成は可能 |
| キャラ画像 | アスタリス外にも全員が残っていたため表示を限定。控えの変更・リセットは再編成後に可能。隠れた控えの既存画像データは保持 |
| 保持した購入計画 | 離脱した人物の予定を自動削除しない。「同行していない仲間の購入予定」と表示し、本人名・装備詳細は再編成後に表示。購入には新見積の確認が必要 |
| 木人試用 | 補助役を固定IDから選んでいたため控えが同行して見えた。補助役も現在の編成から選択。ポーターだけの編成では勝利回復試用に攻撃できる仲間が必要と表示し、控えを代入しない |

アスタリスでは控えの人物・装備・スキル・成長・持ち物を閲覧し、編成に加えることができます。閲覧は所有物を移す操作ではありません。所持品や個別画像を削除せず、控えから再加入しても、在庫・装備・HP/MP・成長・画像割当をそのまま使います。

`roster()` と保存スキーマには手を加えず、表示用の `visible_roster()` を追加しました。読込時の画像ID検証は全11人を使います。隠れた人物の画像が未知ID扱いで拒否されることはありません。旅のrollback内にも控えの個別在庫を保持します。消耗品の既存総数上限は変更していません。
