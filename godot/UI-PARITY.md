# 旧Python UIとの再照合と補完

2026-10-07、親の表示パリティ補完指示に対応。対象は通常起動するCampaign画面（`Start-5525.cmd` → `journey_app.py` → `CampaignApp`）と、そこで呼ばれる配置・戦闘・木人です。デバッグ用の旧独立Journey/単独Battleの専用QA入口は、通常Campaignの移行対象と混同していません。

前回報告の模式地図、依頼/旅程詳細、装備比較/仲間詳細を補完しました。旧画面の関数単位で再読し、同種の省略があった宿屋、結果、戦闘詳細、画像説明、保存先選択も補いました。ゲームルールや新しい施設・依頼・装備は追加していません。

## 意図して維持する差異・未確認

- 戦闘の別ウィンドウは単一Godotウィンドウへ統合。旧色・ピクセル単位のレイアウト一致は目的としません。
- セーブとログの既存ファイル上書きは拒否。これは旧セーブ保全の指示に基づく制限です。任意の新規保存先は選べます。
- 現行Pythonで未実装のスキルポイント配分、ノースの固有施設などは追加していません。
- 実ユーザーセーブは未提供。旧fixture・生成した進行・画像埋込を検証。元ファイルの初期化/上書きはしていません。
- 音声検証はDummyドライバー。実スピーカー出力・人の聴感、全スキル/全装備の手操作網羅は未確認。
- export/配布・commit/push・通常適用なし。配布条件は [EXPORT-READINESS.md](EXPORT-READINESS.md)。
