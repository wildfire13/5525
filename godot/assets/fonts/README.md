# UI font

Noto Sans JP (variable weight), distributed under the SIL Open Font License 1.1.
See `OFL.txt` for attribution and license terms.

Source: https://github.com/google/fonts/tree/main/ofl/notosansjp

The common theme uses weights 450 (body), 550 (controls), 650 (headings),
and 700 (low-HP emphasis). Bundle the font so Japanese text metrics are
consistent across machines.
