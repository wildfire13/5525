# 施設NPCの試用素材

ユーザー提供のPNG原本7枚。本試作への利用許可を受けて組み込んだ候補素材です。画像は加工せず、元のPNGバイトを保持しています。表示時の縮尺・位置・領域だけを調整します。

- 全て1024×1536・RGBA。合計13,515,244 bytes。
- `manifest.json` は配置先・SHA256・寸法の照合用です。元の資料のURL、アカウントや私的台帳は収録しません。
- 武器屋は `weapon1.png` / `weapon2.png` を入店ごとに等確率で選択。同じ滞在中は固定し、連続同一を許容します。
- 防具店・道具店・装飾品店・宿屋・ギルドは各同名PNGを固定使用。地図・出発画面にはNPCを追加しません。
- 元画像内の透明余白、淡い発光・影も保持しています。透過の加工や再生成はしていません。
