# 施設NPCの試用素材

ユーザー提供のPNG原本9枚（武器屋2・防具店1・道具店1・装飾品店1・宿屋1・ギルド3）。画像は加工せず、元のPNGバイトを保持しています。表示時の縮尺・位置・領域だけを調整します。

- 全て1024×1536・RGBA。マニフェスト登録9枚の合計 19,048,279 bytes。
- `manifest.json` は配置先・SHA256・寸法の照合用です。元の資料のURL、アカウントや私的台帳は収録しません。
- 武器屋は `weapon1.png` / `weapon2.png`、ギルドは `guild-dwarf.png` / `guild-elf.png` / `guild-human.png` を入店ごとに等確率で選択。同じ滞在中は固定し、連続同一を許容します。
- 防具店（`armor.png`）・道具店（`item.png`）・装飾品店（`npc_accessory_shop.png`、`エルフ_男_装飾店員_01.png` 原本バイト）・宿屋（`inn.png`）は固定使用。地図・出発画面にはNPCを追加しません。
- 元画像内の透明余白、淡い発光・影も保持しています。透過の加工や再生成はしていません。
