# 比較窓の文字・サイズとショップ行高の調整

先行候補 `885a9533406623615019337bd240f0a488cf90e4` に対する限定的な表示調整。

## 変更

- 性能比較の文字サイズを共通テーマの22px相当から18pxへ変更。色分けは維持。
- 520×480固定の比較窓を廃止。通常幅200〜420px、内容に応じた高さ48〜360pxとし、長文は折返し＋スクロールにする。ウィンドウ右側の空き幅を優先し、不足時は左へ退避。外側に余地のない最大化相当の配置では装備ボタン列を覆わない左側に置く。元のステータス窓自体は移動・縮小しない。
- 初期中央配置のFHD検証では、「＋俊足」は200×51px、HP上限＋55／行動速度−1の2行は240×78px。両方ともx1488から右側に表示され、ステータス外枠と重ならない。
- ショップ商品行は標準64pxへ変更。レイアウト初期の狭い幅で計測した高い最小高さが残る原因を修正。子コンテナの `minimum_size_changed` も監視し、幅と折返し計算が落ち着いてから必要高を再計測する。
- 短い通常商品は全8行とも64px、足フィルターの2行も64px。長い名前では必要な分だけ高くなり、名前が短く戻る／画面が広く戻る場合は縮む。価格・購入・木人ボタンは維持。

ゲームのルール、確認トークンと世代管理、装備・在庫の消費処理、ウィンドウ保存形式、カメラ操作・保存コードは変更していない。装飾品の仕様とCCTは対象外。
