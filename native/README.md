# 5525 Native Prototype — 正式ゲームプレイ・プロトタイプ

Python/Tkのネイティブ画面に、既存5525の戦闘・旅程・プレイログのルールを接続した正式ゲームプレイ・プロトタイプです。2026-10-02に現行機能のテスト可能性を独立レビューで確認し、正式指定しました。元のWeb版は比較用に保持しています。

## 起動

Python 3 + Tk、Node.js 22以上が必要です。今回のクラウド環境では既存のPython3.13 / Tk8.6 / Node24.19.0を使用し、追加インストールはしていません。

```sh
python journey_app.py
```

戦闘単体版は画面右上の「戦闘単体版」、または以下で起動します。

```sh
python app.py
```

Windowsではリポジトリ直下の `Start-5525.cmd` をダブルクリックしてください。既存Python 3 + TkとNode.jsを確認し、見つからない場合は説明を表示します。インストールは行いません。Pythonは `py -3`、`python`、既存の `%USERPROFILE%\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe` の順で確認します。`NATIVE5525_PYTHON` にPython実行ファイルの絶対パスを設定した場合はそれを優先します。

Linuxでは `native/` 内で以下を実行します。

```text
python3 journey_app.py
```

- 旅程：受注 → 最大5人の編成（ポーター必須）→ 補給/配置方針 → 道選択 → 配置 → 戦闘 → 野営 → 二戦目 → 配達 → 報酬 → 再挑戦
- 配置：味方ボタンで選択して置き先をクリック、またはドラッグ。味方のいるマスは交換。金枠は陣形、青は通常攻撃範囲、緑枠は奇襲可能な敵
- 戦闘：コマンド → 緑の対象 → 確定。取消/Escでは消費なし。移動の仮位置で攻撃/スキル範囲・陣形・着地点への敵予告を確認できます
- 移動は一行動です。移動後の攻撃は次の本人の番。敵はAGI順に自動行動します
- 旅程の戦闘は別のネイティブウィンドウに開きます。終了後「戦闘を終えて街道へ」。旅程ウィンドウから戦闘再開・JSONログ保存ができます
- ログは明示的な保存のみ。進行セーブ/ロードや自動送信ではありません

## QA局面

「QA」と明示された項目は境界確認用です。通常プレイやバランス評価と混同しないでください。

## 明示している違いと限界

- ネイティブ2D画面です。Web版Three.jsの立体街道/荷車、被弾/回復パーティクル、登場アニメーションは再現していません。数値・予告・結果は盤面/文章で確認できます
- 通常攻撃・アイテム・防御にも追加の確定操作があります。ルール上の消費や結果は同じです
- 盤面は共通10×5座標を一続きに表示し、陣地色で左右を区別します
- 本書の実GUI証拠はクラウドLinux上の検証です。Windowsランチャーを同梱していますが、Windows実機の検証は別途必要です。インストーラーはありません
- Tkのアクセシビリティ情報は汎用X11コンテナーのため、実GUI検証はスクリーンショットと座標入力を使用しています
- プロセス停止時の復旧・進行保存は未実装。元Web版にも進行セーブ/ロード、音声、装備変更、連続受注、独立イベントシステムはありません
- すべての敵抽選/編成を実GUIで通しプレイしたという意味ではありません。境界・組合せはルールテスト、代表フローは実GUIで分けて確認しています
- ログ保存エラー時の復旧UIは未実機検証です。保存成功・取消は実GUIで確認しています
